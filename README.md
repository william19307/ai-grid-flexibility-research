# AI 算力负荷灵活性与中国电力系统

这是我们的研究同步仓库，记录研究目标、研究过程、已核实证据、模型实现、审计结果和论文工作稿。

## 研究目标

研究题目暂定为：

**AI 算力负荷灵活性的电力系统价值、兑现边界与激励机制——基于中国算电协同的研究**

核心问题是：在完成同等数量和质量的 AI 服务、保持同等供电可靠性的条件下，训练、批量推理和实时推理的时间、功率与空间灵活性，能够为电力系统带来多少可验证的成本、投资和排放变化？企业自主运行能够兑现多少？什么样的承诺、补偿和履约机制能够改善参与？

研究证据链为：

`任务服务约束 → 可执行功率响应 → 电力系统价值 → 企业行为 → 激励机制`

目标载体是完整博士论文，并从最有说服力的结果中形成一篇面向 Nature Energy 的英文核心论文。期刊定位不是结果保证。

## 当前已落实

- 完成直接竞争研究的初筛与创新边界审计。
- 复核公开 GPU 功率—吞吐量实验：8 个配置、48 条记录，并完成留出插值误差检查。
- 下载并审计 BurstGPT v2.0 第一部分 1,429,737 条请求元数据。
- 建立逐批任务、服务期限、功率响应、恢复与承诺成本模型。
- 建立计算任务与发电、储能、输电投资运行的联合线性模型。
- 加入水量守恒的梯级水电约束；联合模型 118 项检查、水电扩展 74 项检查通过。
- 审计 PyPSA-China V3.0 2020 年 8,784 小时输入、输电条目和资产年份边界。
- 核对官方 2020 年核电机组统计、可靠性报告以及大型水电投运年份。
- 转录 31 省 2020 年官方用电量，完成年度负荷锚定和江苏月度时间结构诊断。
- 已修正准备文件中时间戳声明与实际单位不一致的问题，并验证功率与新能源数组未改变。
- 取得并审计三套公开生产 GPU 集群轨迹（Helios、阿里 PAI、Philly），提取排队等待、运行时长与利用率分布。
- 建立 31 省选区筛选矩阵；把联合模型接成单省 S0/S0b/S1/S2 管线并完成三省未校准粗跑。

## 当前最重要的证据边界

2020 年分省年度负荷锚定已经完成，但源模型逐时形状仍不是独立实测的 2020 年负荷。年度总量吻合不能替代逐时、峰荷、发电结构和可靠性回测。因此仓库中所有结果都明确区分：

1. 公开实测或官方统计；
2. 已审计的源模型输入；
3. 数学验证案例；
4. 尚未完成的地区系统结果；
5. 仅用于排版的虚构 Mock 数据。

## 复现与同步

在本机安装项目所需 Python 依赖后，可运行 `work/research/analysis/` 下对应脚本。脚本会把结果写入 `outputs/research/`，并在审计 JSON 中记录来源与状态。当前仓库的研究状态以 `outputs/research/reports/研究进度与待完成项.json` 为准。

同步到其他地方时：

```bash
git pull --rebase
git add outputs work/research/analysis work/research/models README.md .gitignore
git commit -m "Update research evidence and manuscript"
git push
```

这是研究工作仓库，不是投稿版本。正式论文、可公开数据和代码包将在完成许可核对、地区回测和独立可靠性验证后另行冻结版本。

# 阶段 08：可调整煤电机组承诺的模型实现与核验

2026-09-22。阶段 07 的真实任务四格实验仍在运行；本阶段是联合电网模型的独立扩展，不改变该实验的冻结算法或已投稿文件。

**完成范围：固定容量机组的启停、最短开停时间、爬坡和成本已进入同一个联合优化模型，75 项新增数学检查、118 项既有电力/任务检查、74 项水库检查通过。尚未完成真实省级参数校准、逐机组案例重算或全年可靠性验证。**

## 为什么需要这一步

旧模型按刚性 AI 负荷决定煤电可用容量，再将该容量用于其他情景。阶段 03 已修正无 AI 参考随 AI 规模变化的问题，但仍不能让各情景自主决定哪些机组启动。新扩展允许每台指定机组在各时段开机或停机，同时支付相应成本；无 AI 与 AI 可以使用相同物理设备和初始条件，各自优化承诺。

启停与爬坡的基本形式参照 [PyPSA 官方方法说明](https://docs.pypsa.org/latest/user-guide/optimization/unit-commitment/)。这里新增的是本项目的独立实现和核验，不声称使用了 PyPSA 求解器或其完整机组模型。

## 模型定义与边界

对固定装机机组，状态 u、启动 y、停机 z 为二元变量，满足 u(t)−u(t−1)=y(t)−z(t)，每时段至多一次状态变化。出力在开机最小出力与可用容量之间，停机时为零；预知不可用时段禁止开机。最小出力使用额定容量比例，不随可用率缩小而被暗中放松。

连续运行的爬坡限值以 MW/hour 输入，并乘时步小时数；启动、停机的限值使用 MW。启动和停机成本按事件收取，不随时间步长缩放；无负荷成本按开机小时收取。所有运行成本按情景概率加权，设备容量和物理约束不按概率缩小。启停成本归入运行成本，资金转移不在这里计入。

初始开停状态、连续维持时长及出力必须显式一致。跨左边界的最短开停义务继续执行；右边界尚未完成的义务随终态输出。后续滚动窗口必须继承终态，单个短窗口结果不证明尾部义务已兑现。不同情景当前使用同一给定初态；它不是历史机组状态重建。

启停扩展只用于固定装机机组，拒绝将同一机组同时设为连续扩容量对象。其他机组和储能仍可使用原有投资变量，不能把未加启停控制的新增燃机自动称为经过完整机组承诺验证。

原电力平衡、线路、储能、水库水量和计算任务变量均保留在同一个模型内。未提供承诺配置时走原 LP；提供后使用 SciPy/HiGHS MILP。求解超时或其他未解决状态与“证明不可行”分开记录。只有求解成功并通过残差与整数检查的结果被接受。MILP 不输出假装是边际价格的 LP 对偶变量；若后续需要价格，必须另定义固定承诺定价或机制规则。

## 核验及实际结果

| 核验 | 结果 |
|---|---|
| 独立整数出力穷举 | 64 个小案例；覆盖初态、最短开停时间、爬坡、启动/停机限值、预知可用率、不同时间步长；最优成本误差 0 |
| 新增全部检查 | 75 项；另含成本单位、左右边界、任务联合优化、储能、线路与水库、多机组选择、情景概率和无效输入 |
| 原电网与任务核验 | 118 项；含 60 个容量解析参照和 40 个任务分配穷举；独立功率平衡误差 0 |
| 原水库核验 | 74 项；含 60 个独立动态规划参照；独立水量和电力平衡误差 0 |

穷举参照不调用新增启停约束构造器：直接枚举出力路径，按设备状态持续时间和相邻出力差剔除不合法路径，再重算成本。所用单机组加无限制备用的整数参数构造，对固定状态路径具有整数差分约束多面体，因此整数出力枚举是这些小案例的精确参照，不是随机抽查连续域。

结果与代码快照在 `commitment/validation/`。未覆盖原 `outputs/research/tables/` 冻结核验表。

## 尚未解决的研究问题

1. 缺少各实际机组最小出力、爬坡、启动成本、初态和检修/停运校准。容量清单本身不提供这些运行参数。
2. 当前可用率是事先知道的计划约束；不模拟不可预知强迫跳闸、故障相关性或事故后的特殊启停豁免。启动燃料及排放也未单独建模。
3. 完美预知运行、线性运输网络、固定水耗和连续任务分配等原模型边界仍存在。真实 GPU 整组排程需通过外部已核验轨迹接入，不能被流体任务变量替代。
4. 尚未进行固定投资的全年样本外调度、极端天气及等可靠性比较。数学检查通过不能转换成省级容量价值结论。
5. 尚未据此改写主文数值或发布新的能效/时移占比；下一步必须在相同任务、整机功率假设/校准、物理设备和信息条件下重算。

## 真实机组清单新增发现

逐 ID 恢复原始 GEM 表字段后，三省既有 2030 选择的 391 台煤电机组中有 226 台明确标注 CHP，165 台 CHP 字段未知；89 台有自备/特定用途字段记录。明确 CHP 容量占比在甘肃、江苏、贵州分别为 51.92%、38.25%、13.23%。两类标签重叠，不能相加；自备标签也不等于完全离网。恢复的字段说明仅补启停模型仍不够，供热和可外送边界必须继续核实。完整摘要见 `commitment/fleet_audit/煤电运行参数证据缺口.md`。

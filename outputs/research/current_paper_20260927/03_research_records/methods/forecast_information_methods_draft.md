# Working methods for decision-time information

23 September 2026. Source qualification and version-selection implementation; historical provincial forecasts have not yet been admitted.

Information disclosure requirements and observed information availability are separate evidence categories. The national disclosure rule specifies audience classes and disclosure timing, but it does not prove that a particular archived numerical version was available before a historical decision. A release deadline, file name, operating date, document metadata or present-day download timestamp is insufficient on its own. The national rule's original Word attachment was obtained from two official hosts with identical hashes; its forecast-field inventory and relevant timing/audience provisions were checked across text extraction and rendered-source review. Provincial rule applicability must still be established for the actual study period. [National Energy Administration notice and attachment](https://zfxxgk.nea.gov.cn/2024-01/31/c_1310763726.htm).

Each normalized curve must identify the signal, geographical/technology boundary, unit, interval-start timestamps, interval length, source file and publication version. Source review separately binds the snapshot hash to a raw-source hash, availability-evidence hash and verified availability timestamp. The software checks this binding; it cannot authenticate a publisher or establish publication provenance without that external review. All decision and interval timestamps require explicit UTC offsets. Unit conversions and interval-end-to-start normalization must be supported by source metadata before admission.

For a requested decision cutoff and delivery horizon, the selector uses the latest complete eligible version available no later than the cutoff. It does not splice releases, interpolate missing intervals or fill forecasts with realized observations. A newer incomplete release is excluded with an explicit reason; an older complete admissible release may remain usable. Conflicting latest release timestamps return an ambiguity state instead of a result-dependent tie-break. Missing provenance or eligible coverage returns unavailable. Later revisions remain in the audit trail and are excluded from the earlier decision.

Seventeen synthetic logic checks cover late revisions, cutoff equality, time zones, snapshot tampering, incomplete releases, scope/units, interval-end shifts, contemporaneous ambiguity and missing evidence. These checks establish implementation behaviour, not actual forecast accuracy or freedom from leakage in a yet-unobtained empirical dataset. The production admission registry is empty. The selector has not yet been connected to the main experiment, rolling grid commitment or uncertain task arrivals. No forecast-performance or operational mechanism claim is supported by this stage.

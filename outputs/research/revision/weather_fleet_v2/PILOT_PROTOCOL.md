# 技术分离与网格选择接入试验

冻结日期：2026-09-23。试验只检验接口选择、返回网格与气象序列变化，不证明真实发电量、风机功率或省级代表性。

候选范围为 July-2025 GEM 库存中三省 operating 机组，共 2,902 条；使用阶段 15 恢复的编号。分开陆上风电、海上风电、光伏和光热。以 geoBoundaries 固定版本 CHN ADM1 多边形筛查明显地理异常：陆上场址距离所属省粗边界超过约 50km 的 6 条记录（277MW）待核实；近边界保留并标注，不自动认定错误。5 条光热（410MW）不进入光伏转换。所有未进入天气候选的容量单独保留，不把它们当作不存在。

地理来源：[geoBoundaries API 元数据](https://www.geoboundaries.org/api/current/gbOpen/CHN/ADM1/)，边界 ID CHN-ADM1-43563684，表示年份 2019，发布文件固定提交 9469f09。实际 GeoJSON 与其 Git LFS 指针 SHA256 `3a00467a0db9b4136facb5f2f3d0edbfd96adb15651cfdf63991da9281030e85` 一致。该粗多边形不适合确认边界附近或海上项目位置。

完整候选在 0.25°最近中心上聚合，原始单位容量、技术分类和编号保留；421 个不同候选格点不是 421 个独立样本。此处只是减少同格重复请求的设计，还没有启动全部网格采集。真实返回格点必须再核对，不能假设接口必然等于所算格心。`Assumed PV` 保留来源假设标签；历史投运年未知、2020 年内投运月份未知，以及现代库存的幸存机组偏差均不填补。

先在甘肃陆上、贵州陆上、江苏陆上、江苏海上四组中，分别选择**没有粗边界标记的最大容量机组，编号升序打破容量并列**。选择不使用气象结果或收益大小。每个场址配对比较最近格点与 land/sea 偏好（陆上 land、海上 sea），统一 elevation=nan 关闭接口海拔降尺度。保持原场址坐标不变，显式 ERA5，2020 全年加 2021-01-01 边界，共 8 个请求。单位 m/s、hPa、W/m²、°C；原始返回单位和元数据保存。

参数依据：[Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api) 的 cell_selection 与 elevation 说明。land/sea 是格点选择偏好，不是观测质量等级；nearest 也不保证山地风速或沿海资源准确。前小时平均辐射和时点变量仍按各自时间含义处理。

调用共用阶段 13 的滚动额度台账与进程锁，使用相同保守阈值和至少 6 秒间隔。旧站点暂停标记保持生效；新入口仅允许这份冻结的 8 请求方法试验，不能用它批量续传旧清单或绕过服务限额。出现网络错误即停止并保留记录。

准入检查：原始与科学内容哈希、完整 8,808h、时间唯一/连续、明确时区、七变量单位/有限性、两种请求相同场址/时间/变量。比较返回网格、风速均值及小时差异，不用试验挑选“最符合想要结果”的请求或宣布某格点为真实值。试验之后仍须核对坐标、设备转换、海陆掩膜及同范围观测，才能冻结正式多年请求。
